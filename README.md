## 🧠 AI 与内容

- ⚗️ **[Distilled · ai.makinote.cn](https://ai.makinote.cn)**
  不用再刷 AI 资讯流：200+ 信源每天蒸馏成今日导读、实体追踪和洞察，附开放数据。
- 🖥️ **[makino-distilled](https://github.com/makinotes/makino-distilled)**
  同一份 Distilled 装进 Claude Code，在终端里读日报，按主题追长期趋势，不追热点。
- 📊 **[makino-data-slides](https://github.com/makinotes/makino-data-slides)**
  分析结论直接变成文章级配图：ECharts 图表或静态卡片，Playwright 出图，省掉做图和排版。
- 🖼️ **[makino-content-to-html](https://github.com/makinotes/makino-content-to-html)**
  一篇长文一条命令变成 slides、网页、deck 或海报，8 套风格预设，单文件随手分享。
- ✍️ **[makino-writing-craft](https://github.com/makinotes/makino-writing-craft)**
  给 AI 写作助手加一层质量把关：34 万字写作方法论蒸馏成 7 条原则、10 个模块、28 项自检。
- 🗂️ **[htmlvault](https://github.com/makinotes/htmlvault)**
  选一个本地文件夹，AI 生成的 HTML（slides、图表、看板）自动分类成画廊，文件不离开你的机器。
